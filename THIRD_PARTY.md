# Third-party asset credits

## Anatomical head base — MakeHuman hm08

The head in `src/assets/castiel-head.json` is a modified, head-only extraction of
MakeHuman's hm08 basemesh, smoothed with one Catmull-Clark subdivision and fitted
to the game's character. This is a generic anatomical base, not a scan of Misha
Collins or a model from The Witcher. No other part of the source mesh is shipped.

Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj

The source file explicitly states that it was released under **CC0 in September
2020**. Its listed copyright holders at release are Data Collection AB, Joel
Palmius and Jonas Hauquier. License: CC0 1.0 Universal.

License statement: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md
Full asset license: https://creativecommons.org/publicdomain/zero/1.0/

Source OBJ SHA-256: `8e761e6624b8f54536409135d1636da63b32486a90d4897f84e121d144f6fb4c`.
The full CC0 text is saved in `src/assets/MAKEHUMAN-CC0.md`.

To reproduce the extracted asset, download that source file and run:

```
python tools/build_head.py /path/to/base.obj
```

Costume, hair, hands, accessories, environments and effects are generated by this
project. Three.js, Vite and other dependency licenses remain with their packages.
