# Сверхъестественное: Последняя благодать

Неофициальная одиночная фан-игра в 3D на Three.js. Не связана с правообладателями сериала. Все модели и окружение созданы процедурно; музыка, актёрские фотографии и материалы сериала не используются.

## Играть без npm и установки

После успешной публикации откройте **https://kostya08062005-hub.github.io/supernatural/** в Chrome, Edge или Firefox на компьютере. Ничего скачивать и запускать в терминале не нужно. Выберите карту и нажмите «Начать охоту». Нужны клавиатура, мышь и включённое аппаратное ускорение браузера.

### Однократное включение GitHub Pages владельцем репозитория

1. Откройте https://github.com/kostya08062005-hub/supernatural/settings/pages.
2. В разделе **Build and deployment** выберите **Source → GitHub Actions**.
3. Перейдите на вкладку **Actions** и откройте **Publish game to GitHub Pages**. Если GitHub просит разрешить workflows, включите их.
4. Нажмите **Run workflow → main → Run workflow**. Если предыдущий запуск завершился ошибкой до включения Pages, запустите новый.
5. Дождитесь зелёных отметок у задач **build** и **deploy**. Затем откройте ссылку на игру выше. Публикация может занять несколько минут; до её завершения адрес может возвращать 404.

В дальнейшем обновления `main` публикуются автоматически. npm используется только на серверах GitHub для сборки, игрокам он не нужен. Если выбор GitHub Actions недоступен, проверьте права администратора и доступность Pages для текущего тарифа и видимости репозитория.

## Локальный запуск для разработки

Нужны Node.js 20.19+ или 22.12+ и современный настольный браузер с WebGL 2 (Chrome, Edge, Firefox), аппаратное ускорение и клавиатура с мышью.

```sh
cd /workspace/supernatural # либо каталог вашего клона
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно порт 5173). В удалённой среде используйте проброс этого порта. Для локальной игры интернет нужен только при установке пакетов: внешние ресурсы во время игры не загружаются.

Сборка и проверка готовой версии:

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`; размещайте её на обычном статическом HTTP-сервере. Открытие `index.html` через `file://` не поддерживается.

## Визуальная версия 0.2

Мрачная палитра и камера у плеча ориентированы на атмосферу фэнтезийных RPG. Это процедурный браузерный прототип, а не графика уровня «Ведьмака 3»: для такого качества нужны детализированные персонажи, окружение, скелетные анимации и отдельный художественный пайплайн.

- Касание: сближение → подъём руки с движением локтя → ладонь у головы демона → нарастание бело-голубого света → выжигание → отведение руки. Урон наносится после контакта, а не сразу при нажатии. Во время приёма движение заблокировано; пауза замораживает анимацию.
- Крылья: широкие теневые силуэты с перьями, раскрывающиеся на фоне яркой благодати; вместо проволочных сфер — световые ореолы, искры, bloom и динамическое освещение.
- Карты: текстурированные земля, камень и дерево, растительность, камни, сумеречная палитра и туман. Процедурные текстуры не требуют скачивания внешних ассетов.

## Игра

В меню выберите Кастиэля и одну из двух карт: «Тихий погост» или «Чёрный лес». Нажмите «Начать охоту». Цель — изгнать 15 демонов, сохранив здоровье. Демоны появляются волнами, преследуют игрока и наносят урон вблизи. Изгнание восстанавливает 5 здоровья.

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение относительно камеры |
| Левый Shift | Бег |
| Правая кнопка мыши + движение | Поворот камеры |
| Q | Чёрные крылья и сияние благодати: 75 урона в радиусе 8 м, краткая неуязвимость, восстановление 8 с |
| E | Касание ближайшего демона до 3 м: 100 урона, восстановление 3 с |
| Esc | Пауза / продолжение |

Атаки также доступны кнопками внизу экрана. После победы или поражения можно повторить охоту или вернуться к выбору карты. Потеря фокуса окна автоматически ставит игру на паузу.

Кастиэль — стилизованная процедурная модель: короткие тёмные волосы, голубые глаза, бежевый плащ с лацканами, белая рубашка, синий галстук, тёмный костюм и чёрные крылья. Это не фотореалистичная копия лица Миши Коллинза. Выжигание показано световой вспышкой и исчезновением демона без натуралистических повреждений.

## Проверка

```sh
npm run build
npx playwright test
```

Автоматическая проверка использует установленный Chromium (`/usr/bin/chromium`). Если он отсутствует, выполните `npx playwright install chromium`; конфигурация автоматически использует скачанный браузер. Тесты проверяют меню, обе карты, движение, атаки, паузу, возврат и отсутствие ошибок браузера. Это первый игровой прототип: один персонаж, две карты, без сохранений и сетевого режима.
