# Сверхъестественное: Последняя благодать

Неофициальная одиночная фан-игра в 3D на Three.js. Не связана с правообладателями сериала. Все модели и окружение созданы процедурно; музыка, актёрские фотографии и материалы сериала не используются.

## Запуск

Нужны Node.js 20.19+ или 22.12+ и современный настольный браузер с WebGL 2 (Chrome, Edge, Firefox), аппаратное ускорение и клавиатура с мышью.

```sh
cd /workspace/supernatural # либо каталог вашего клона
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно порт 5173). В удалённой среде используйте проброс этого порта. Для локальной игры интернет нужен только при установке пакетов: внешние ресурсы во время игры не загружаются.

Сборка и проверка готовой версии:

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`; размещайте её на обычном статическом HTTP-сервере. Открытие `index.html` через `file://` не поддерживается.

## Игра

В меню выберите Кастиэля и одну из двух карт: «Тихий погост» или «Чёрный лес». Нажмите «Начать охоту». Цель — изгнать 15 демонов, сохранив здоровье. Демоны появляются волнами, преследуют игрока и наносят урон вблизи. Изгнание восстанавливает 5 здоровья.

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение относительно камеры |
| Левый Shift | Бег |
| Правая кнопка мыши + движение | Поворот камеры |
| Q | Чёрные крылья и сияние благодати: 75 урона в радиусе 8 м, краткая неуязвимость, восстановление 8 с |
| E | Касание ближайшего демона до 3 м: 100 урона, восстановление 3 с |
| Esc | Пауза / продолжение |

Атаки также доступны кнопками внизу экрана. После победы или поражения можно повторить охоту или вернуться к выбору карты. Потеря фокуса окна автоматически ставит игру на паузу.

Кастиэль — стилизованная процедурная модель: короткие тёмные волосы, голубые глаза, бежевый плащ с лацканами, белая рубашка, синий галстук, тёмный костюм и чёрные крылья. Это не фотореалистичная копия лица Миши Коллинза. Выжигание показано световой вспышкой и исчезновением демона без натуралистических повреждений.

## Проверка

```sh
npm run build
npx playwright test
```

Автоматическая проверка использует установленный Chromium (`/usr/bin/chromium`). Если он отсутствует, выполните `npx playwright install chromium`; конфигурация автоматически использует скачанный браузер. Тесты проверяют меню, обе карты, движение, атаки, паузу, возврат и отсутствие ошибок браузера. Это первый игровой прототип: один персонаж, две карты, без сохранений и сетевого режима.
