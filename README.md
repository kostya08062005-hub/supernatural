# Сверхъестественное: Последняя благодать

Неофициальная одиночная фан-игра в 3D на Three.js. Не связана с правообладателями сериала. Окружение, одежда и эффекты созданы процедурно; анатомическая основа головы — MakeHuman CC0 (см. THIRD_PARTY.md); музыка, актёрские фотографии и материалы сериала не используются.

## Играть без npm и установки

После успешной публикации откройте **https://kostya08062005-hub.github.io/supernatural/** в Chrome, Edge или Firefox на компьютере. Ничего скачивать и запускать в терминале не нужно. Выберите карту и нажмите «Начать охоту». Нужны клавиатура, мышь и включённое аппаратное ускорение браузера.

### Если при открытии пустой экран

1. Дождитесь успешного завершения `build` и `deploy` во вкладке Actions, затем обновите игру сочетанием Ctrl+F5.
2. Попробуйте облегчённый режим без bloom: https://kostya08062005-hub.github.io/supernatural/?graphics=basic.
3. В Chrome проверьте Settings → System → Use graphics acceleration when available и перезапустите браузер после изменения. Облегчённый режим тоже требует WebGL 2.
4. Если показано «Не удалось запустить игру», откройте «Текст ошибки». Сообщение о неразрешённом импорте `three` означает, что опубликованы исходники вместо сборки: выберите Source → GitHub Actions в настройках Pages и повторите публикацию.

При загрузке теперь отображается заставка, а при ошибке JavaScript или WebGL — диагностическое сообщение и кнопка облегчённого режима.

### Однократное включение GitHub Pages владельцем репозитория

1. Откройте https://github.com/kostya08062005-hub/supernatural/settings/pages.
2. В разделе **Build and deployment** выберите **Source → GitHub Actions**.
3. Перейдите на вкладку **Actions** и откройте **Publish game to GitHub Pages**. Если GitHub просит разрешить workflows, включите их.
4. Нажмите **Run workflow → main → Run workflow**. Если предыдущий запуск завершился ошибкой до включения Pages, запустите новый.
5. Дождитесь зелёных отметок у задач **build** и **deploy**. Затем откройте ссылку на игру выше. Публикация может занять несколько минут; до её завершения адрес может возвращать 404.

В дальнейшем обновления `main` публикуются автоматически. npm используется только на серверах GitHub для сборки, игрокам он не нужен. Если выбор GitHub Actions недоступен, проверьте права администратора и доступность Pages для текущего тарифа и видимости репозитория.

## Локальный запуск для разработки

Нужны Node.js 20.19+ или 22.12+ и современный настольный браузер с WebGL 2 (Chrome, Edge, Firefox), аппаратное ускорение и клавиатура с мышью.

```sh
cd /workspace/supernatural # либо каталог вашего клона
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно порт 5173). В удалённой среде используйте проброс этого порта. Для локальной игры интернет нужен только при установке пакетов: внешние ресурсы во время игры не загружаются.

Сборка и проверка готовой версии:

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`; размещайте её на обычном статическом HTTP-сервере. Открытие `index.html` через `file://` не поддерживается.

## Версия 0.4: референсы, передвижение и способности демонов

Собственная адаптация модели переработана по четырём присланным ракурсам: более узкий серо-бежевый тренч до колен, открытая белая рубашка, тёмные брюки, более плоские туфли, складки ткани и приподнятые волосы. В режиме **«Рассмотреть Кастиэля»** можно вращать модель, выбирать лицо/полный рост и включать синий галстук. Кнопка **«Скачать модель GLB»** сохраняет собственную версию персонажа вместе с текстурами прямо из браузера. Это статическая модель с отдельными частями; скелет и анимационные клипы для стороннего редактора не экспортируются. Основа головы остаётся MakeHuman CC0; это не скачанная модель Sketchfab и не скан актёра. Источник анатомической сетки и лицензия — в THIRD_PARTY.md. Прямой доступ к указанной странице Sketchfab блокируется сетью текущей облачной среды; её лицензию и скачиваемый файл проверить не удалось.

- Мышь поворачивает камеру и самого Кастиэля. Кнопку удерживать не нужно. Щелчок по игровому миру захватывает мышь для непрерывного вращения; Esc освобождает её и открывает паузу. Если захват запрещён браузером, обычное движение мышью продолжает работать.
- **Пробел** — прыжок с гравитацией и приземлением. Повторный прыжок в воздухе невозможен.
- **C** — перекат в направлении движения (без движения — вперёд), краткая неуязвимость. Перекат останавливается у препятствий; восстановление 1,4 с.
- **R** — телепортация вперёд до 10 м, в свободное место в пределах карты, восстановление 6 с. Телепорт может переносить через препятствие, но не внутрь стены.
- **F** — удержать демона в теле по прицелу на расстоянии до 12 м на 6 с. Препятствие блокирует захват. Повторное F отпускает его. Пока он обездвижен, подойдите и нажмите E. Восстановление 10 с; удерживаемый демон не атакует и не превращается в дым.
- Демоны периодически покидают тело, оставляя падающую оболочку, летят чёрным дымом к другой позиции и снова обретают тело. Улетевший демон остаётся противником, а не засчитывается как изгнанный. Дым нельзя захватить F, но благодать Q уничтожает его в своём радиусе.
- **Q** раскрывает две мягкие теневые формы крыльев без объёмных перьев. Во время активного свечения демоны в радиусе 8 м испаряются; касание E тоже заканчивается испарением. Пауза останавливает таймеры, полёт дыма, прыжок и распад.

Теперь три карты. На кладбище добавлены арка, руины, скамьи, колодец и дополнительные захоронения; в лесу — река с двумя мостами и новый ритуальный круг. **«Заброшенный завод»** содержит цеха, трубы, бочки, ящики и рельсы. На картах есть проходы и физические препятствия.

### Освещение и анимация

Мрачная палитра и камера у плеча ориентированы на атмосферу фэнтезийных RPG. Это процедурный браузерный прототип, а не графика уровня «Ведьмака 3»: для такого качества нужны детализированные персонажи, окружение, скелетные анимации и отдельный художественный пайплайн.

- Касание: сближение → подъём руки с движением локтя → ладонь у головы демона → нарастание бело-голубого света → выжигание → отведение руки. Урон наносится после контакта, а не сразу при нажатии. Во время приёма движение заблокировано; пауза замораживает анимацию.
- Крылья: широкие теневые силуэты с перьями, раскрывающиеся на фоне яркой благодати; вместо проволочных сфер — световые ореолы, искры, bloom и динамическое освещение.
- Карты: текстурированные земля, камень и дерево, растительность, камни, сумеречная палитра и туман. Процедурные текстуры не требуют скачивания внешних ассетов.

## Игра

В меню выберите Кастиэля и одну из трёх карт: «Тихий погост», «Чёрный лес» или «Заброшенный завод». Нажмите «Начать охоту». Цель — изгнать 15 демонов, сохранив здоровье. Демоны появляются волнами, преследуют игрока и наносят урон вблизи. Изгнание восстанавливает 5 здоровья.

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение относительно камеры |
| Левый Shift | Бег |
| Мышь | Поворот камеры и персонажа; щелчок по миру захватывает указатель |
| Пробел | Прыжок |
| C | Перекат |
| R | Телепортация |
| F | Удержание демона / отпустить |
| Q | Чёрные крылья и сияние благодати: уничтожает демонов в радиусе 8 м во время свечения, краткая неуязвимость, восстановление 8 с |
| E | Касание ближайшего демона до 3 м: 100 урона, восстановление 3 с |
| Esc | Пауза / продолжение |

Атаки также доступны кнопками внизу экрана. После победы или поражения можно повторить охоту или вернуться к выбору карты. Потеря фокуса окна автоматически ставит игру на паузу.

Кастиэль — игровая модель с анатомической головой на основе MakeHuman CC0 и процедурной одеждой: короткие тёмные волосы, голубые глаза, бежевый плащ с лацканами, белая рубашка, синий галстук, тёмный костюм и чёрные крылья. Это не фотореалистичная копия лица Миши Коллинза. Выжигание показано световой вспышкой и исчезновением демона без натуралистических повреждений.

## Проверка

```sh
npm run build
npx playwright test
```

Автоматическая проверка использует установленный Chromium (`/usr/bin/chromium`). Если он отсутствует, выполните `npx playwright install chromium`; конфигурация автоматически использует скачанный браузер. Тесты проверяют меню, обе карты, движение, атаки, паузу, возврат и отсутствие ошибок браузера. Это первый игровой прототип: один персонаж, три карты, без сохранений и сетевого режима.
